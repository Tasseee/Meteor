# Belege – Screenshots und Logs

Lege Belege nur ab, wenn sie tatsächlich vom Nutzer oder einem Testlauf bereitgestellt wurden. Verknüpfe sie im jeweiligen Testbericht.

Empfohlene Ablage:

`NIGHTFALL/EVIDENCE/<Modul>/<Test-ID>/`

Screenshots sollten den relevanten Zustand zeigen, ohne unnötige private Informationen. Logs vor dem Speichern auf Tokens, Session-IDs, Passwörter, persönliche Daten und private Serveradressen prüfen und diese entfernen.

Keine Platzhalterbilder oder erfundenen Logs einsetzen. Bei großen Logs nur den relevanten Ausschnitt speichern und Herkunft sowie Version angeben.
