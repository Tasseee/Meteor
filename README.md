# Nightfall

Clientseitiger Minecraft-Utility-Client für Fabric (Bewegungs-, Kampf-, ESP- und Weltwerkzeuge).

## ⬇ Neueste Version herunterladen

**[Nightfall – aktuelle Version herunterladen](https://github.com/Tasseee/Meteor/releases/latest/download/nightfall-latest.jar)**

Die Datei wird nach jedem erfolgreichen Build von `main` aktualisiert. Verwende für die Installation immer diesen Link und keine alte JAR aus dem Quellcode oder einem früheren Actions-Lauf.

## Version und Anforderungen

- Aktuelle Quellversion: 0.5.20
- Minecraft: 1.21.11
- Mod-Loader: Fabric Loader >= 0.18.1
- Java: >= 21
- Benötigt: Fabric API

## Installation

1. Lade die JAR über **Neueste Version herunterladen** herunter.
2. Lege `nightfall-latest.jar` in den `mods`-Ordner deiner Modrinth-Instanz.
3. Stelle sicher, dass Fabric API installiert ist.
4. Entferne ältere Nightfall-JARs aus demselben `mods`-Ordner, damit nicht zwei Versionen gleichzeitig geladen werden.
5. Starte Minecraft.

SeedCrackerX ist bereits in der JAR enthalten und muss nicht separat installiert werden.

## Builds

Jeder erfolgreiche Build auf `main` veröffentlicht einen neuen GitHub-Release. Pull Requests und Feature-Branches werden gebaut und geprüft, aber nicht als neuester Release veröffentlicht.
